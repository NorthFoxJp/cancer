## 4. GitHub Pagesのrobots.txt

このサイトはプロジェクトサイト`https://northfoxjp.github.io/cancer/`です。リポジトリから生成されるrobots.txtは`/cancer/robots.txt`に置かれますが、robots.txtの正式な適用場所はホスト直下の`https://northfoxjp.github.io/robots.txt`です。

`northfoxjp.github.io`本体のリポジトリを管理している場合、ホスト直下のrobots.txtにも次を追加してください。

```text
User-agent: *
Allow: /cancer/
Sitemap: https://northfoxjp.github.io/cancer/sitemap.xml
```

本体リポジトリを使っていない場合でも、Search Consoleから`/cancer/sitemap.xml`を直接送信できます。
